One excuse, in the agent's own voice, for a missed deadline — blamed squarely on its own machinery: "I spent my entire token budget writing the plan to meet the deadline, so I had nothing left to actually do it." `main.ts` (Node 22 stdlib only) checks the line is 1–200 characters, then writes it to `/output/entry.txt`. Same bytes on every run, no randomness, no network, no clock.

## Run it

```sh
node main.ts
```
